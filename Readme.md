# Описание проекта
> Temporal-Anomaly - это игровой движок и прототип 2D-приключенческой игры, разработанный на Pygame. Игрок исследует различные комнаты, находя скрытые предметы и раскрывая тайны через взаимодействие с окружающей средой. Каждая локация является частью общей истории, которая развивается по мере продвижения игрока.

# Технологии
- Язык программирования: Python 3
- Игровой движок: Pygame
- Хранение данных: Файловая система (.txt файлы)
- Архитектура: Объектно-ориентированное программирование (ООП)

# Ключевые особенности реализации
## Система хранения данных
- Карты уровней: Хранение структуры комнат и расположения объектов в .txt файлах
- Прохождение: Сохранение концовок 
- Конфигурация игры: Настройки и начальные параметры через текстовые файлы

## Игровая архитектура
- Кастомные классы объектов: Реализация игровых сущностей через ООП
- Система взаимодействий: Механики взаимодействия игрока с объектами окружения
- Управление состоянием игры: Отслеживание прогресса и открытых локаций

## Технические компоненты
- Загрузчик карт: Парсинг .txt файлов для генерации игровых комнат
- Система коллизий: Обнаружение столкновений между игроком и объектами
- Игровой цикл: Оптимизированный главный цикл с обработкой ввода и рендерингом

# Функциональность
- ✅ Генерация игрового мира из файловых описаний
- ✅ Система перемещения между комнатами
- ✅ Взаимодействие с объектами окружения
- ✅ Сохранение и загрузка прогресса
- ✅ Обнаружение скрытых предметов и механизмов

# Особенности разработки
## Архитектурные решения:
- Своя реализация систем классов
- Гибкая система загрузки контента, позволяющая легко расширять игровой мир
